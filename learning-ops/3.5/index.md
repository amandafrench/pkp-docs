# Learning OPS 3.5: A User Guide to Open Preprint Systems

* [English](./en)

Learning OPS 3.5 is a guide for how to use Open Preprint Systems (OPS), an open source application for managing the posting of preprint research papers. 

* [Learning OPS for Site Administrators](./en/site-admin) will help you learn how to install and maintain OPS. 
* [Learning OPS for Preprint Server Managers](./en/preprint-server-manager) will help you learn how to develop policies and workflows for your preprint server.
* [Learning OPS: The Editorial Workflow](./en/editorial-workflow) will help you learn more about the options for the simplified editorial workflows that characterize a preprint server. 
* [Learning OPS for Moderators](.en/moderator) will help you learn how to moderate preprint submissions and the workflow for declining or posting them. 
* [Learning OPS for Authors](.en/author) will help you learn how to submit preprints to OPS. 

This guide can be used alongside [Learning OJS 3.5](/learning-ojs/), which has information about how to use OPS that is common to both OPS and Open Journal Systems (OJS) – a similar open source software application for publishing scholarly journals.
